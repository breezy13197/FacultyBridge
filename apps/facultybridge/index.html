About FacultyBridge

FacultyBridge is the shared home for seven focused tools that simplify faculty workflows between systems. Each tool remains independent, while the suite provides consistent navigation, design, and interaction patterns.

This standalone v1.2 package expects sibling folders named SyllabusBridge, CalendarBridge, QuestionBridge, ExamBridge, ItemBridge, GradeBridge, and GroupBridge. Destinations are configured in assets/facultybridge.js.

Tool colors are intentionally distinct across the suite: SyllabusBridge amber, CalendarBridge orange, QuestionBridge green, ExamBridge purple, ItemBridge teal, GradeBridge blue, and GroupBridge coral.
