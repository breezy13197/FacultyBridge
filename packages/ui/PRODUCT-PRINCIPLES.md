# Faculty Tools Product Principles

Faculty Tools are designed for faculty members first. Technical sophistication should stay behind the interface.

1. **Faculty should not need technical knowledge.** Use familiar academic terminology and hide file-format complexity.
2. **Make the next action obvious.** Each screen should have one clear primary action.
3. **Preview before committing.** Faculty should be able to inspect edits, mappings, conversions, and output before download or irreversible action.
4. **Never silently discard data.** Unsupported or ambiguous content must be surfaced with a clear warning and resolution path.
5. **Errors should teach the user what to do next.** Prefer “This student could not be matched — choose a student or exclude this row” over generic error codes.
6. **Preserve the original whenever practical.** Imports, edits, and exports should not force users to lose source information.
7. **Prefer visual editing over syntax editing.** Users should manipulate questions, students, mappings, categories, and settings through familiar controls.
8. **Minimize required steps.** Advanced capabilities can exist, but should not complicate basic workflows.
9. **Use progressive disclosure.** Show essential controls first; move expert settings into expandable or contextual areas.
10. **Local/private processing is preferred for sensitive academic material.** If data leaves the device, make that clear.
11. **Validation is a feature, not an obstacle.** Validate continuously and explain incompatibilities early.
12. **Consistency across Faculty Tools matters.** Shared navigation, colors, status patterns, form controls, and interaction language should feel familiar across applications.
13. **Accessibility is part of the design.** Keyboard access, visible focus, sufficient contrast, semantic markup, and non-color status cues are required.
14. **Responsive does not mean cramped.** On smaller screens, stack interfaces rather than shrinking complex workspaces beyond usability.
15. **The interface should feel calm and professional.** Use generous whitespace, restrained color, subtle shadows, and plain language.
