records, exams, private reports, or confidential filenames/paths in a public copy.

- [ ] Full automated validation passed on the exact release commit.
- [ ] Private regression and applicable release checklist gates are complete,
      or exceptions are explicitly recorded and accepted.
- [ ] Draft ZIP contents match the build manifest and were exercised from the
      extracted/distributed copies, including offline standalone use.
- [ ] Notes and artifacts contain no private material.
- [ ] Reviewer approves publication of these artifacts.
- [ ] Draft explicitly published; canonical distribution and replacement
      instructions updated.
- [ ] Post-publication smoke check passed from the shared location.
